# API 接口文档生成器

根据用户提供的模块目录路径，读取源代码中的 Controller/路由/DTO 等文件，生成符合模板规范的 API 接口设计文档。

## 使用方式

```
/api-doc <模块目录路径>
```

示例：
- `/api-doc src/main/java/com/example/controller`
- `/api-doc src/modules/user`
- `/api-doc src/api/v1`

## 执行步骤

### 1. 读取模板

先读取 `${CLAUDE_SKILL_DIR}/template.md` 获取文档模板结构。

### 2. 分析模块目录

使用 Glob 和 Grep 工具扫描用户提供的目录，识别：
- **Controller 文件**：查找路由定义（如 `@RestController`、`@GetMapping`、`@PostMapping`、`@RequestMapping` 等注解，或 Express/Flask 等框架的路由定义）
- **DTO/VO/Entity 文件**：查找请求体和响应体的数据结构定义
- **枚举文件**：查找接口中使用的枚举类型定义

### 3. 收集必要信息

如果以下信息无法从代码中推断，需要向用户确认：

- **系统名称**：如「商城系统」「用户中心」等
- **端名称**：如「商家端」「用户端」「管理端」等
- **认证方式**：默认为 JWT Bearer Token，如有不同需确认
- **响应结构**：默认使用模板中的 `code/message/data` 结构，如有不同需确认
- **公共路径前缀**：每个模块的请求路径前缀（通常可从 `@RequestMapping` 等注解推断）

### 4. 生成文档

按照模板结构生成文档，每个模块包含以下内容：

#### 模块信息
```markdown
## {{模块中文名}}

### 模块信息

**当前模块接口请求公共路径前缀**：`{{path_prefix}}`
```

#### 接口定义（每个接口）
```markdown
### {{序号}}. {{接口名称}}

#### 基本信息

**接口描述**：{{从代码注解或方法名推断}}

**请求方式**：`{{GET/POST/PUT/DELETE}}`

**请求路径**：`{{路径}}`

#### 请求说明

**请求头参数**：（如有特殊头信息）

**路径参数**：（如有路径参数）

**请求参数（Query String）**：（如有查询参数）

**请求体参数**：（如有请求体）

**请求数据示例**：

（生成合理的 JSON 示例）

#### 响应说明

**响应数据示例**：

（生成合理的 JSON 示例）

**响应字段说明**：

| 字段名 | 类型 | 说明 |
|--------|------|------|
（从 DTO/VO 中提取字段定义）
```

### 5. 生成附录

收集文档中引用的所有枚举类型，在附录中统一定义：

```markdown
## 附录

### 枚举值定义

#### {{枚举名称}}

| 枚举值 | 说明 |
|--------|------|
| {{value}} | {{description}} |
```

## 生成规则

1. **接口名称**：从方法名和注释推断，使用中文动词+名词格式（如「获取用户信息」「创建订单」）
2. **请求参数**：从 DTO/方法参数中提取，标注类型和是否必填
3. **请求数据示例**：**每个接口都必须包含请求数据示例**。对于 POST/PUT 请求生成 JSON 示例；对于 GET 请求生成 Query String 格式示例（如 `?page=1&pageSize=10&keyword=手机`），即使只有分页参数也要展示；无参数接口展示完整请求路径即可
4. **响应示例**：根据字段类型生成合理的示例数据
5. **枚举定义**：收集所有引用的枚举，在附录中统一列出
6. **分页接口**：响应使用模板中的分页结构，`records` 字段的具体结构单独说明
7. **无响应体接口**：如删除、状态变更等操作类接口，标注「响应数据：无（空 body，状态码 200 表示操作成功）」

## 注意事项

- 文档语言使用中文
- JSON 示例中的缩进使用 4 个空格
- 字段类型使用 Java 常见类型名称（Integer、Long、String、Boolean、BigDecimal、Array、Object 等）
- 如果模块目录包含多个子模块（子目录），按子目录分组生成多个模块章节
- 保持与现有接口文档模板（`template.md`）的格式完全一致
